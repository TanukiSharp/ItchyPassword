Description of service

ItchyPassword is a free, open-source, client-side password manager built with Blazor WebAssembly. It runs entirely in your browser and performs all cryptographic operations locally. The application is provided as-is, hosted on GitHub Pages.

No account required

ItchyPassword does not require you to create an account. There is no registration, no email collection, and no user profile. Your master key is the sole means of accessing your encrypted vault, and it is never stored anywhere.

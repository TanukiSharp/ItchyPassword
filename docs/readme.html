ItchyPassword

Privacy-first, offline-capable password manager.

This project is built with Blazor WebAssembly. All cryptography happens locally in your browser via the SubtleCrypto API. There is no server, no backend, and no telemetry.

Note: The Blazor version (v2) is available at: tanukisharp.github.io/ItchyPassword/vnext

How it works with Google Drive

ItchyPassword can optionally use Google Drive as a storage connector to sync your encrypted vault across devices. When you grant access, the application uses the drive.file scope, meaning:

  • It can only access files that it has created itself.
  • It cannot see, read, or delete any other files in your Google Drive.
  • Your data is encrypted with your Master Key before being uploaded. Even Google cannot read your passwords.

Features overview

Master key security

Your master key never leaves your machine and is never stored anywhere — not even encrypted. It lives in memory only while the tab is open.

Vault Management

  • Static keys: Deterministic passwords derived from your master key (no storage needed).
  • Secrets: Encrypted free-form text (notes, existing passwords).
  • TOTP support: Live 6-digit codes for 2FA.
  • Metadata: Attach encrypted or plain notes to any item.

Build & Development

Requires .NET 10 SDK or later.

dotnet publish -c Release -p:RunAOTCompilation=true

Technical Details

Feature Implementation
Cryptography SubtleCrypto API (AES-GCM, PBKDF2, HMAC-SHA-512)
Storage GitHub, Google Drive, SOLID Pod, or Local only
Framework Blazor WebAssembly (.NET 10)
